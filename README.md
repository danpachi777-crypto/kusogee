# 温泉宿の消えた記録 — 3D試作版

Blenderで作った温泉宿を一人称視点で探索する、物語付きのステルスゲームです。登場人物は成人です。浴室内や裸の描写はありません。

## Windowsで遊ぶ

このPCでは `Play Onsen Sneak.lnk` をダブルクリックします。初回は物語の画面で「続ける」を押してください。進行状況は自動保存され、次回は到達した章から再開します。

GitHubから取得した場合は [Godot 4.7.2](https://godotengine.org/download/windows/) でこのフォルダの `project.godot` を開き、シーンを実行します。`tools/` 内のGodot実行ファイル、生成キャッシュ、PC固有のショートカットはリポジトリに含めていません。

## スマホ操作プレビュー

このPCの `Play Mobile Preview.lnk` は、スマホ横画面に近い比率で第一章から開きます。タッチ用の画面ボタンはマウスでも押せます。通常のセーブデータを守るため、プレビューでの進行は保存されません。Godotを別のPCで使う場合は `godot --windowed --resolution 1170x540 --path . --script res://mobile_preview.gd` でも起動できます。これはWindowsでの操作確認であり、Android・iPhoneの実機版ではありません。

近づいた物の名前が画面左上に表示されます。金色の目印は温泉宿の調査地点、青緑の目印は山の離れで現在の章に必要な調査地点です。物語画面では「続ける」を押して次の場面へ進みます。選択肢はクリックかタップで選びます。

## 隠れる以外の行動

1. 勤務表を読む: 巡回の交代時刻を知り、しばらく巡回速度を遅くする。
2. 履物を替える: 走るときの足音が届きにくくなる。
3. タオルを持つ: 身支度を整え、視線を集めにくくする。
4. お茶を飲む: 警戒を大きく下げる。一度だけ使える。
5. 館内図を読む: 近くの従業員との距離を表示する。
6. ラジオをつける: 足音を紛らわせる。切り替え可能。
7. 呼び鈴を鳴らす: 従業員を受付へ誘導する。再使用には時間が必要。
8. 照明を落とす: 従業員の視認距離を短くする。切り替え可能。
9. 落とし物の入館証を確認する: 会話の口実になり、視線による警戒を抑える。
10. 古い伝言を読む: 台帳の場所につながる手掛かりが記録に残る。
11. 深呼吸する: 立ち止まると警戒を下げられる。再使用には時間が必要。

前の試作からの行動として、受付で入館札を受け取る、鏡で変装を整える、従業員に道を聞く、小銭で注意をそらす、走る、しゃがむ、立ち止まって平静を装うこともできます。

## 物語

- 第一章「消えた入館記録」: 受付と館内を調べ、奥の赤い入口へ進む。
- 第二章「奥の保管通路」: 机の鍵を見つけ、保管棚の台帳を調べる。
- 第三章「台帳の欠落」: 証拠を持って受付へ戻る。
- 第四章「山の離れからの電話」: 三件の通話を時系列に並べる。
- 第五章「雨の渡り廊下」: 足音と足跡のどちらを抑えるか選んで進む。
- 第六章「二冊目の台帳」: 偽名を照合する。
- 第七章「夜勤の従業員」: 相手の事情を考えて話を聞く。
- 第八章「停電の時間」: 明かりと巡回の変化を選ぶ。
- 第九章「宿泊客の証言」: 聞く順番で得られる情報が変わる。
- 第十章「失われた写真」: 写真と改築図から封鎖室を探す。
- 第十一章「離れの管理人」: 手持ちの証拠と信頼で交渉する。
- 第十二章「記録の持ち出し」: 時間内に原本を複写して戻す。
- 第十三章「真相と次の目的地」: 証拠の強さに応じて結末が分岐する。
- 第十四章: 選んだ結末を引き継ぎ、次の調査先を決める。
- 第十五章: 湖畔の資料館か町役場へ移動し、欠けた記録を再調査する。
- 第十六章: 見つけた原本で結論を補強し、次の事件へつなぐ。

前回の10案は第四章から第十六章の遊べる内容にしました。各章の関係は `NEXT_STORY.md` に記載しています。

入口を通るだけでは終了しません。警戒が最大になると章の開始地点へ戻りますが、調べた情報は残ります。章の進行は `user://onsen_story_save.json` に保存されます。

## 制作ファイルと対応機種

- `game_v4.gd`: 一人称視点、10章の調査、選択、警戒、分岐、保存。
- `blender_source/`: 温泉宿と人物の Blender 元データ。
- `build_assets.py`: Blender 用の素材生成スクリプト。
- `tests/gameplay_smoke.gd`: 温泉宿の行動と章進行の確認。
- `tests/campaign_smoke.gd`: 10案を通る正解ルートと移動の確認。
- `tests/campaign_branch_smoke.gd`: 失敗と別の結末の確認。

Godotの同じプロジェクトをAndroidとiPhone向けに使う設計です。Windowsでの試作動作は確認済みです。Android実機への書き出しにはGodotのエクスポートテンプレート、JDK、Android SDKが必要です。iPhone向けアプリの書き出しにはmacOS、Xcode、Appleの署名設定が必要です。スマホ実機での性能とタッチ操作は未確認です。

床と石材のテクスチャは [Poly Haven のCC0素材](https://polyhaven.com/license) を使用しています。日本語フォントは Noto Sans JP で、ライセンスは `assets/OFL.txt` にあります。人物の見た目と動きはまだ試作段階で、実写に近いモデルやモーションキャプチャ素材は未導入です。
